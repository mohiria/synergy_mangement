# 协同管理工具领域词汇

本文件定义“综合项目协作与推进”产品中的统一业务语言，避免需求、原型和研发使用同一词语表达不同概念。

## Language

**任务概况**：
面向项目整体查看场景的任务只读摘要，包含任务事实、当前交付物和协作上下文；不承载编辑、审批或状态变更。存在候选交付物时只提示有更新正在审核，不把候选内容展示为正式成果。
_Avoid_: 任务编辑面板、任务操作台

**任务基础信息**：
用于识别任务归属、责任、计划和当前推进事实的只读信息，包括任务编号、所属 O／KR、状态、负责人、参与人、开始与截止时间、可选进度、任务说明、完成标准、当前环节和待行动人。
_Avoid_: 必要输入、交付物、协作关系、任务编辑表单

**任务讨论**：
绑定到具体任务、供所有项目内成员发表文字意见并 @ 项目内成员的平铺协作记录；只有查看权限的成员也可以参与，意见提交后不可编辑或删除，纠正时追加新意见。新增意见只通知任务负责人和被 @ 的成员；它不支持附件、多层回复或独立聊天会话，不等同于审批意见，也不直接改变任务状态。
_Avoid_: 审批意见、操作日志、群聊、讨论线程

**任务审核**：
对任务入池、关键字段修改或任务完成申请进行确认或退回的业务环节。申请人负责发起，当前待行动审核人负责通过或退回，其他项目成员只查看流程和结果。
_Avoid_: 任务讨论、任务状态编辑、仅指完成审核、全员审批

**审核记录**：
任务各次审核的业务事实，记录审核类型、申请与处理相关人员及时间、申请内容、状态、等待时长、结果和意见；关键字段修改保留修改前后差异，完成审核关联本次候选交付物。审核记录持续保留；交付物被覆盖时仅删除旧交付内容，不删除相关审核记录。
_Avoid_: 交付物历史版本、讨论记录、操作日志

**交付物**：
任务向接收方或下游任务正式提供的成果关系，一个任务可以产生多项交付物。首版每项交付物只保留一份当前交付内容，不形成历史版本。
_Avoid_: 工作附件、孤立文件、交付物历史版本

**工作附件**：
任务执行过程中使用、尚未作为正式成果提交审核的过程资料。它不进入任务概况的当前交付物，也不作为下游正式输入。
_Avoid_: 当前交付物、候选交付物、正式成果

**当前交付物**：
已经审核生效、当前供接收方或下游任务使用的交付内容；一个任务的多项当前交付物可以同时存在，不使用版本号。更新内容在终审通过后覆盖对应交付物项，被覆盖的旧内容永久删除且不可追溯。
_Avoid_: 最新版本、历史版本

**候选交付物**：
为替换当前交付物而提交、正在等待审核的临时交付内容；项目成员可以查看和下载，只有当前待行动审核人可以处理。它不作为正式成果或下游输入；终审通过后覆盖当前交付物，审核退回后删除，不留存为历史版本。
_Avoid_: 草稿版本、待生效版本、历史版本

**完成申请**：
任务负责人将一项或多项候选交付物提交任务完成审核的业务请求。同一申请中的候选交付物整体通过或整体退回；终审通过后同时覆盖各自对应的当前交付物，未包含的其他当前交付物保持不变。
_Avoid_: 单项部分通过、整任务全部交付物替换

**直接协作关系**：
通过输入或交付物与当前任务直接相连的上游、下游及其责任方。每条关系用于说明对方任务及所属 KR、关系类型、关联交付物、责任人、任务状态和关系就绪情况，不包含需要经过其他任务才能到达的间接关系。
_Avoid_: 完整影响链、全部关系图谱

**影响路径**：
当前任务的变化经由一个或多个协作关系传递到其他任务或 KR 的连续链路，可以包含直接影响和间接影响。
_Avoid_: 直接上下游、单条关系边

**当前环节**：
任务此刻所在的执行、审批或审核阶段，用于说明任务为什么处于当前状态；它是流程事实，不是处理入口。
_Avoid_: 任务状态、审批操作

**待行动人**：
在当前环节中需要执行下一项业务动作的项目成员，可能是任务负责人、审核人或 KR 负责人。
_Avoid_: 任务负责人、参与人

**我的工作事项**：
由任务、审批单、输入请求、待接收项、结构化卡点或任务创建邀请按当前成员职责派生的个人行动或等待事实；同一业务事项只归入一个分组，但同一任务可以因不同业务事实出现在多个分组。
_Avoid_: 新建待办记录、任务副本、通知消息

**任务创建邀请**：
KR 负责人或项目管理员邀请指定成员在某个 KR 下创建任务的行动请求；受邀人通过该邀请提交关联任务的入池申请，或邀请被撤回时结束，同一 KR 下无关任务不会使其结束。
_Avoid_: 任务指派、已创建任务、普通通知

**退回待处理事项**：
关键字段变更被退回后，为原提交人派生的待处理事实，保留退回理由，直到重新提交、明确放弃本次变更或任务终止；仅查看不代表处理完成。
_Avoid_: 已读通知、任务退回状态、永久提示

**审批超时**：
审批件在当前审批环节持续等待达到项目级阈值 N×24 小时的事实；进入新的审批环节后重新计时，处理或关闭后解除，并形成对应的结构化卡点。
_Avoid_: 从申请最初提交时间累计、临期提醒、任务超期

**风险等级**：
用于说明任务或 KR 当前风险程度的独立事实，统一分为正常、预警和高风险；它只反映真实风险，不由未开始、等待输入、待审核或已完成等任务生命周期状态自动推导。
_Avoid_: 任务生命周期状态、审核状态、完成进度

**结构化卡点**：
绑定到具体任务的风险事实，记录缺失的输入或条件、阻塞原因、待行动人、持续时间和影响范围，并具有预警或高风险等级。
_Avoid_: 一般任务状态、审批等待、没有事实说明的颜色标记

**必要输入**：
任务开始或继续推进前必须获得的内容、文件或条件，其来源可以是已有任务交付物或指定项目成员。
_Avoid_: 参考资料、可选附件

**输入就绪**：
必要输入已经满足任务使用条件；来自已有任务时须有已生效的当前交付物，来自指定成员时须已完成内容提交。
_Avoid_: 已同意接收、已上传草稿

**交付物边**：
从来源任务或实际承担输入责任的项目成员指向下游任务的有向协作关系，记录交付物名称、关系类型、必要性、提供方、接收方和就绪状态；当前交付物与候选交付物关联在这条边上，不形成独立图谱节点。
_Avoid_: 交付物节点、孤立文件节点、无方向关系

**O／KR 层级视图**：
只表达项目中 O 与下属 KR 的归属结构，不承载 KR 之间或 O 之间的任务协作关系；风险通过节点事实和风险队列表达。
_Avoid_: KR 聚合关系图、KR 汇总关系边、目标协作网络

**KR 任务关系视图**：
从某个 KR 下钻后，以该 KR 的任务为主体，并纳入与其直接相连的其他 KR 任务，通过交付物边表达真实输入输出关系。
_Avoid_: 仅展示本 KR 任务、KR 汇总关系边

**关系相关项目成员**：
直接参与输入或交付流转的项目成员，包括被指定提供输入，或尚未形成上游任务但承担交付责任的成员；卡点待行动人只作为任务风险事实展示，不因此成为关系相关项目成员。
_Avoid_: 全部项目成员、普通任务参与人、仅作为属性展示的负责人

**关系就绪状态**：
交付物边能否向下游提供正式可用输入的系统判断。只有已生效的当前交付物可以使关系就绪；候选内容不能提前满足输入，已有当前内容时的候选更新也不改变原有就绪状态。
_Avoid_: 任务生命周期状态、候选内容已提交、文件已上传

**受影响目标**：
任务或卡点沿下游硬前置交付物边可能拖累的 KR 或 O，由系统根据真实关系推导并展示对应影响路径；它不同于任务直接归属的 O／KR。
_Avoid_: 所属目标、所有下游关系、反馈关系推测影响

**硬依赖链**：
由硬前置交付物边形成、但因任务计划时间或里程碑信息不足而只能确认先后依赖、不能完成传统关键路径计算的关系链。
_Avoid_: 关键路径、普通信息输入链、反馈循环

**只读甘特视图**：
“全部任务”模块的 P1 辅助视图，按 O／KR 分组展示任务计划时间、状态、里程碑和硬前置关系；不允许拖拽改期，日期修改仍通过关键字段变更审批完成。
_Avoid_: 协作关系图谱、甘特编辑器、资源排程工具
