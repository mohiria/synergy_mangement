## 复现方式

本机无 Docker，服务手装在 `~/sdk`：

```bash
~/sdk/pgsql/bin/pg_ctl -D ~/sdk/pgdata -l ~/sdk/logs/postgres.log -o "-p 5432 -k /tmp" start
MINIO_ROOT_USER=synergy MINIO_ROOT_PASSWORD=<取本机 .env> \
  ~/sdk/bin/minio server ~/sdk/miniodata --address :9000 --console-address 127.0.0.1:9001 &

export PATH=$HOME/sdk/go1.26.7/bin:$PATH
export DATABASE_URL="postgres://synergy@localhost:5432/synergy?sslmode=disable"

cd server && go build ./... && go vet ./... && go test -count=1 ./...
SEED_PASSWORD='<自定口令>' go run ./cmd/seed          # 注意：清空全部业务数据
cd ../web && npm run build && SEED_PASSWORD='<自定口令>' npm run test:e2e
```

标准环境（有 Docker）按 CLAUDE.md 走 `docker compose up -d postgres minio` 即可；集成测试自带 goose 迁移，跑前不需要手工建库。Gotenberg 本机起不来，报告导出那条集成测试会自动 skip。
