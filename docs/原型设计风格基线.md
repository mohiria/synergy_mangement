# 原型设计风格基线（V4.5 / collaboration-prototype-v2）

提取自 `collaboration-prototype-v2/`（Calm Operations 2.0），是 `web/` 视觉还原的唯一依据。旧原型 `collaboration-prototype/` 及其基线（本文件 git 历史中的旧版）已废弃，仅作参考。

**CSS 加载与覆盖顺序（核对时必须按此判断生效值）**：

1. `styles.css` —— 基础层；其尾部有两个覆盖块：「V4.1 visual baseline」（约 66 行起，覆盖 :root token）与「V4.4 typography contract」（约 260 行起，定义 --type-title/body/aux 并全局映射字号）；
2. `collaboration-prototype.css` —— 只作用于关系图谱页（cp-* 前缀）；
3. `redesign-v1.css` —— **最终覆盖层**，重定义全部 :root token 与大多数组件；其**文件尾部「V4.4 surface contract」块用 `border-radius: 4px !important` 强制所有矩形元素 4px 圆角**（头像、状态圆点、开关等圆形语义控件例外为 50%/999px）。因此文件中段出现的 8～12px 圆角声明一律被尾部覆盖，生效值是 4px。

核对时以浏览器实际渲染为准。

## 2. 阴影层级（V4.5 硬性规定）

- **一级（普通卡片）**：`0 1px 2px rgba(24,34,52,.025)`，用于 card、toolbar、data-table-wrap、graph-shell、cp-surface、work-board 等所有平铺容器；
- 浮层（popover / 搜索候选）：`0 20px 46px rgba(24,34,52,.16)`；
- 弹窗：`0 26px 72px rgba(20,29,50,.22)`；抽屉：`-24px 0 60px rgba(20,29,50,.18)`；
- 更高层级阴影只用于弹窗、抽屉和浮层，普通卡片一律一级灰阴影（PRD §10.3）。

## 3. 字号契约（12/14/16，styles.css 尾部 typography contract）

- `--type-title` 16px：页面 h1、卡片/弹窗/抽屉/区块标题（card-head、drawer-head h2、modal-head h2、drawer-section h3、objective-head h2 等）；
- `--type-body` 14px：body、按钮、输入框、表格 td、task-tabs、文字按钮；
- `--type-aux` 12px：面包屑、页面副题、状态徽章、表格 th、表单 label、meta/时间、upload-zone 说明、图谱边标签与节点说明等一切次要信息；
- 内容区不额外制造 16px 小标题（PRD 决策 33）。

## 4. 圆角契约

- 通用矩形元素（按钮、输入框、卡片、弹窗、抽屉内容卡、状态徽章、表格容器等）一律 **4px**（redesign-v1.css 尾部 `!important` 契约）；
- 例外（保持圆形/胶囊）：.avatar、.project-dot、图例圆点 50%；.toggle、cp-completed-toggle 滑块 999px；status 前置圆点、指示点 50%；
- antd 自带的胶囊形组件同样豁免，不纳入 4px 断言：通知徽标 `.ant-badge-count` 7px、开关 `.ant-switch` / `.ant-switch-inner` 100px。
