# 原型设计风格基线

提取自 `collaboration-prototype/`，是 `web/` 视觉还原的唯一依据。**注意：`styles.css` 前半段是废弃旧稿，文件尾部「V4.1 visual baseline」覆盖块（约 66 行起）才是生效样式**；`collaboration-prototype.css` 只作用于关系图谱页（cp-* 前缀）。核对时以浏览器实际渲染为准。

## 2. 字号契约（V4.4 硬性规定）

- 标题 16px：页面 h1、卡片/弹窗/抽屉标题、brand 名称
- 正文 14px：正文、按钮、输入框、表格 td
- 辅助 12px：页面副标题、面包屑、状态徽章、表格 th、表单 label、meta/时间等一切次要信息

## 3. 壳层

- 侧边栏：**浅色** #eef2f6，宽 232px，右边框 #cbd4df，内边距 0 4px 8px（nav 区 0 8px）
- brand：高 62px、无下边框；brand-mark 34×34、圆角 9px、底色 #23334d、白字、weight 600；名称 16px，副题 12px muted
- nav-row：高 38px、圆角 7px、默认字色 #526070；hover 底 rgba(255,255,255,.75)；激活 **白底 + #25365d + 细阴影 0 1px 2px rgba(29,43,67,.08) + weight 600**
- 顶栏：高 60px、padding 0 24px、底 rgba(255,255,255,.92) + blur、下边框 --line；面包屑 12px muted，分隔符 `/`（.sep #abb4bd），当前页加粗深色
- 身份按钮：高 38px、白底、描边 --line、圆角 7px，内含头像（25px）+ 姓名
- 页面容器：max-width 1520px，padding 24px 26px 40px；page-head h1 16px/600，副题 12px muted

## 4. 组件

- 按钮 .btn：高 **34px**、圆角 7px、weight 500；默认白底描边 #cbd4df 字色 #344152；primary 底/描边 #5267df 白字，hover #4559ca；compact 30px；链接色 --accent
- 状态徽章 .status：高 26px、**圆角 5px**、padding 0 7px、12px/500，前置 6px 圆点；green=normal/done/active、amber=warning/pending、red=risk/blocked、violet=review、灰 #eef1f4/#53606d=中性
- 表格：容器描边 --line 圆角 10px；th 高 38px、底 #f7f9fb、字色 #657184、12px/600；td 高 44px、下边框 #e9edf0；行 hover #fafbff；O 分组行（.table-group）底 #f2f5f8、字色 #415067、weight 600
- 表单控件 .field：高 34px、圆角 6px、描边 --line
- 卡片 .card：白底、描边 --line、圆角 10px；card-head 高 48px 下边框
- notice：底 #eef0ff、字色 #4655a4、左边框 3px #7c89df、圆角 6px
- 弹窗：圆角 9px、标题 16px、遮罩 rgba(15,28,38,.28)；okr-modal 宽 min(1080px, 100vw−32px)
- okr-sheet：描边 --line 圆角 8px；表头高 38px 底 #f5f7fa 字色 #657184 12px；行 min-height 54px 下边框 #edf0f4；列（原型）210/240/110/170/290/36
- 空态 .empty：padding 42px 20px 居中 muted

## 5. antd 落地约定

- ConfigProvider token：colorPrimary/colorLink #5267df、colorBgLayout #f5f7fa、colorText #1f2937、colorBorder #cbd4df、colorBorderSecondary #dfe5ec、borderRadius 7、controlHeight 34
- 组件 token：Button fontWeight 500 / defaultColor #344152；Table headerBg #f7f9fb / headerColor #657184 / headerSplitColor transparent / rowHoverBg #fafbff / 圆角 10；Modal 圆角 9、标题 16px；Card 圆角 10
- antd 覆盖不到的（分组行、状态徽章、okr-sheet、壳层）写在 `web/src/ui.css`，类名沿用原型
