# 协同推进系统 V4.5：项目总览与 O/KR 入口合并版

这是从 `collaboration-prototype-v4.4-ui-redesign-v1` 独立复制的新版本，旧版未覆盖。

## 本次变化

- 项目总览的内容和信息结构保持不变。
- 左侧导航移除独立的“OKR 管理”。
- 仅项目推进人／有 O/KR 编辑权限的身份在项目总览页头看到“管理 O/KR”。
- 点击后进入独立全页管理模式，可手动返回项目总览。
- 管理页只维护 O/KR 结构字段：编号、名称、所属 O、负责人、周期、量化标准。
- 管理页不重复展示风险、卡点原因、任务数量、任务进度或任务详情。
- 复用已有导入、新增和编辑交互。
- 新增 O/KR 保存后，按本次事项涉及的负责人发送站内通知；操作者本人不重复接收。

python3 -m http.server 4180

## 推荐验证

1. 默认身份“陈越”进入项目总览，可看到“管理 O/KR”。
2. 点击入口进入全页管理模式，左侧仍高亮“项目总览”。
3. 点击 O 或 KR 行打开右侧编辑抽屉，保存后仍停留在管理页。
4. 新增 O/KR 后确认按钮为“保存并通知负责人”，成功提示包含已通知人数。
5. 切换为本次负责人身份，从右上角通知入口查看 O/KR 分配通知。
6. 点击“返回项目总览”手动返回。
7. 切换为无管理权限身份，项目总览不显示“管理 O/KR”。

其余模块、业务事实与 V4.4 UI Redesign V1 保持一致。
